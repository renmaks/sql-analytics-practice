# Неделя 1 - основы аналитического SQL
Практические задания первой лекции курса.
В рамках модуля отрабатываются агрегатные функции, группировка данных, различные типы JOIN, CTE, оконные функции и работа с датами.

## Задачи:
1. Минимальные и максимальные параметры участников.
2. Участники с ростом выше среднего.
3. Анализ групп участников по росту.
4. Топ-3 самых тяжёлых участников по группам роста.
5. Самые активные сотрудники игрового центра.
6. Клиенты с наибольшими расходами в Москве.
7. Среднее время успешного прохождения квестов.
8. Уникальные посетители сайта за текущий год.

## Файлы
`schema.sql` содержит структуру используемых таблиц и ограничения целостности.
`seed.sql` содержит синтетические тестовые данные для выполнения запросов.
Каталог `solutions/` содержит решения каждой задачи в отдельном SQL-файле.
