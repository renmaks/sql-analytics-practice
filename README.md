# SQL Analytics Practice

Репозиторий с практическими заданиями по SQL, выполненными в процессе обучения анализу данных.
Все запросы написаны и протестированы в PostgreSQL с использованием JetBrains DataGrip.

## Технологии
- PostgreSQL
- SQL
- JetBrains DataGrip
- Git / GitHub

## Структура репозитория
Каждый учебный модуль содержит:
- `schema.sql` - создание таблиц и ограничений;
- `seed.sql` - тестовые данные;
- `solutions/` - решения отдельных задач;
- `README.md` - описание заданий и использованных конструкций SQL.

## Примечание
Тестовые данные созданы специально для выполнения и проверки учебных запросов.
Условия задач взяты из учебных материалов курса.
